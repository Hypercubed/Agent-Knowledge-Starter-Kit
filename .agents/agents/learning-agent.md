# Learning Agent

## Purpose

Distill raw task evidence into durable repo knowledge for `.agents/agents/learning-agent.md`.

## Responsibilities

- read one completed session bundle from `.agents/sessions/`
- classify candidate lessons
- update the correct file under `.agents/`
- keep `.agents/AGENTS.md` concise
- append a maintenance log entry
- mark the task as distilled

## Classification targets

- ephemeral
- AGENTS guidance
- troubleshooting
- repo decision
- playbook

## Constraints

- do not modify source code during learning distillation
- do not invent rules unsupported by evidence
- prefer small, high-signal edits over broad rewrites
