# OpenSpec Integration Guide

This guide describes how to integrate OpenSpec with AKSK.

## MUST: Rules for OpenSpec Agents
- Agents MUST read the `SKILL.md` files in the AKSK repository.
- Agents MUST respect the imperative constraints defined in these skills.
- Agents DO NOT execute scripts; they provide implementation plans based on AKSK knowledge.

## Configuration
See `openspec/config.yaml`.
