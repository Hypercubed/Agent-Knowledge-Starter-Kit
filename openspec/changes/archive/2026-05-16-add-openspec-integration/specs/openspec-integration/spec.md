## ADDED Requirements

### Requirement: OpenSpec Integration Guide
The repository SHALL contain an integration guide instructing users on how to wire OpenSpec with AKSK.

#### Scenario: User wants to integrate OpenSpec
- **WHEN** a user looks in the `docs/integrations/` directory
- **THEN** they find an `openspec.md` file that explains how to use OpenSpec's `rules` block to trigger AKSK `docs-search`, `task-closeout`, and `learning-distill`.
