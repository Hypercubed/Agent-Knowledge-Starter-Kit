## ADDED Requirements

### Requirement: Installation guide merge checklist
The `INSTALL.md` file SHALL include a detailed install and merge checklist specifically for AI agents to follow when adopting the kit.

#### Scenario: AI agent installs the kit
- **WHEN** an AI agent reads `INSTALL.md` during setup
- **THEN** it finds a structured checklist to safely merge new kit components into the repository

### Requirement: Human vs Agent quick starts
The documentation SHALL separate quick start instructions for human consumers versus AI agents.

#### Scenario: Consumer reads quick start
- **WHEN** a human consumer or AI agent reads the README
- **THEN** they find distinct, dedicated quick start sections tailored to their context
